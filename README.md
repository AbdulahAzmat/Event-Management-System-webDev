# Stub · Event Management System

A React app for finding live events, registering for them and keeping track of the ones you're going to.
Built with React, Redux Toolkit, React Router and the Ticketmaster Discovery API.

## Getting started

```bash
npm install
cp .env.example .env   # then add your Ticketmaster Consumer Key
npm run dev
```

The app runs at http://localhost:5173.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serve the production build |
| `npm run lint` | Lint the source |
